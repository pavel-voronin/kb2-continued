# Кандидаты на ошибки

Это список подозрительных мест, найденных при чтении кода. Они не исправлены. Наличие строки здесь ещё не означает, что проблема достижима в обычной игре: для каждого пункта предстоят воспроизведение, проверка причины и согласование исправления. Демонстрации в вебе будут отдельной работой.

Для части пунктов теперь есть модульные воспроизведения в `TEST/HOST/`: они фиксируют текущий результат на явно заданном состоянии. Это подтверждает поведение процедуры, но не всегда достижимость такого состояния обычной игрой. Проверки неверных вызовов зависимостей подтверждают сам неверный запрос, а не последующий исход в DOS.

Для будущего разбора сохраняем отдельно: начальное состояние, последовательность действий, исходный результат, ожидаемое правило и результат исправления. Изменения баланса не считаем исправлением ошибки без отдельного решения.

B017 достигнут обычными действиями бота в инструментированной сборке `continued`: сид мира `-1512480458`, случайный поток бота `232690072`, максимальная сложность. После 535 клавиш поиск `FindUnitCell` зациклился. Диагностическое повторение совпало по всем 487 публичным наблюдениям; затем повторилось полное состояние процессора и 2 МиБ памяти без ввода-вывода между повторениями. В кадре вызова — код клетки 156 при базе 112, то есть запрос слота 100; вызывающий сегмент принадлежит `KBBAI`. Сам код игры не изменён. Запись попытки и отдельное подтверждение сохраняются стендом, повторно подтверждённое зависание не исполняется при чтении отчёта.
