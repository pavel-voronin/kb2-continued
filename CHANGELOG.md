# История изменений

## 1.0.3 - 2026-11-14

- Путешествие у волшебника оплачивается только после выбора доступного континента.
- Отказ оплаты путешествия из-за нехватки золота сохраняет обычный рост отношений с волшебником.

## 1.0.2 - 2026-11-13

- Карта земли текущего острова оплачивается только при её отсутствии.
- Часть древней карты оплачивается только при её отсутствии.

## 1.0.1 - 2026-11-12

- Исправлена повторная покупка стенобитного орудия: если оно уже есть, деньги не списываются, а в меню отображается «Стенобитное орудие куплено».

## 1.0.0 - 2026-11-11

- Начальная версия «Продолжения».
