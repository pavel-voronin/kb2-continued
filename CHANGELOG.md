# История изменений

## 1.0.9 - 2026-11-20

- Усиление воинов растёт до максимума без потери накопленного бонуса, а его дальнейшая покупка отключается.
- Найм работников ограничен максимальным запасом, при полном запасе золото не списывается.
- Неделя завершается без зависания, когда золота ровно хватает на содержание армии, включая случай нулевой казны и нулевых расходов.

## 1.0.8 - 2026-11-19

- При полном запасе смерчей их дальнейшая покупка отключается.

## 1.0.7 - 2026-11-18

- Заселение воинов у волшебника оплачивается, только если есть неполные жилища на текущем острове. Воины сверх нормы сохраняются.
- Достигшая максимума магическая сила сохраняется при получении наград, а её дальнейшая покупка отключается.

## 1.0.6 - 2026-11-17

- Обновление работников у волшебника оплачивается, только если в городах текущего острова не хватает работников.

## 1.0.5 - 2026-11-16

- Изменение воинов у волшебника оплачивается, только если магическая сила позволяет выполнить услугу.

## 1.0.4 - 2026-11-15

- Подсказка волшебника о замке оплачивается, только если есть действующий контракт.

## 1.0.3 - 2026-11-14

- Путешествие у волшебника оплачивается только после выбора доступного континента.
- Отказ оплаты путешествия из-за нехватки золота сохраняет обычный рост отношений с волшебником.

## 1.0.2 - 2026-11-13

- Карта земли текущего острова оплачивается только при её отсутствии.
- Часть древней карты оплачивается только при её отсутствии.

## 1.0.1 - 2026-11-12

- Исправлена повторная покупка стенобитного орудия: если оно уже есть, деньги не списываются, а в меню отображается «Стенобитное орудие куплено».

## 1.0.0 - 2026-11-11

- Начальная версия «Продолжения».
